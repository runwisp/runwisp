RunWisp is one small Go binary that does the job of `crond` plus a
supervisor — and never lets a failure slip past silently. You describe
your tasks and services in a single `runwisp.toml`, and every run gets
an exit code, duration, and captured output you can browse in the
embedded Web UI, watch live in the TUI, or pull over the REST API.
These docs walk you through the whole thing — getting the binary onto a
box, writing that config file, and keeping the daemon happy in
production.

:::note[Pre-1.0]
Any pre-1.0 bump may ship breaking changes and reset run history.
Check the
[CHANGELOG](https://github.com/runwisp/runwisp/blob/main/CHANGELOG.md)
before upgrading. Semver guarantees land with 1.0.
:::

## Looking for something specific?

- **A TOML field you saw in an example** — search this site or jump
  straight to [Configuration overview](/configuration/overview/).
- **A CLI command or flag** — [CLI reference](/reference/cli/) lists every one,
  grouped by what you're trying to do.
- **Something's broken** — [Troubleshooting](/operations/troubleshooting/) is
  organised by symptom, not by subsystem.
- **A REST endpoint** — [API reference](/api/) is generated from the
  OpenAPI schema; the same schema ships as `/openapi.json` from a
  running daemon.
- **A version's breaking changes** — the
  [CHANGELOG](https://github.com/runwisp/runwisp/blob/main/CHANGELOG.md)
  lists them per release.

## Source and contributing

RunWisp is open source under GPL-3.0-or-later and developed at
[github.com/runwisp/runwisp](https://github.com/runwisp/runwisp). Every
docs page has an "Edit this page" link in its footer that points at the
source MDX file — typo fixes and clarifications welcome as PRs against
[`main`](https://github.com/runwisp/runwisp/tree/main/apps/docs).
