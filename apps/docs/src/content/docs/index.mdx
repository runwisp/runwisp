RunWisp is a single binary that replaces cron and a process supervisor. You
describe your scheduled tasks and long-running services in one `runwisp.toml`.
Every run gets an exit code, duration, and captured output, which you can browse
in the built-in Web UI, the terminal UI, or the REST API.

## Where to start

- **New to RunWisp?** Follow [Getting started](/getting-started/quick-start/),
  five short pages from install to a server.
- **Coming from cron, supervisord, systemd, or docker-compose?** Start with
  [Migrating](/coming-from/).
- **Want to look around first?** Run `runwisp demo` for a throwaway instance
  with hundreds of past runs.
- **Looking up a key or a command?** Go to the
  [configuration reference](/configuration/overview/) or the
  [CLI reference](/reference/cli/).

Something broken? Start with [Troubleshooting](/operations/troubleshooting/).
