RunWisp is configured in one file, `runwisp.toml`. It is the only place that
defines what runs: the REST API and Web UI can read and trigger, but never change
task definitions. After editing it, run `runwisp reload` (or send `SIGHUP`). A
few daemon-wide settings need [`runwisp restart`](/operations/reload/).

This page lists every table and key, with links to the reference pages.

## [compose.\<alias\>]

Imports the services of an existing `docker-compose.yml` as RunWisp services.
[Full reference →](/configuration/compose/)

- **Block keys**: [`file`](/configuration/compose/#file), [`services`](/configuration/compose/#services), [`import`](/configuration/compose/#import), [`group`](/configuration/compose/#group), [`project_name`](/configuration/compose/#project_name), [`profiles`](/configuration/compose/#profiles), [`env_file`](/configuration/compose/#env_file), [`working_dir`](/configuration/compose/#working_dir), [`with_deps`](/configuration/compose/#with_deps), [`pull`](/configuration/compose/#pull), [`name_format`](/configuration/compose/#name_format)
- **Overrides**: `[compose.<alias>.defaults]` and `[compose.<alias>.<service>]` accept most [`[services.*]`](/configuration/services/) keys. See [Per-service overrides](/configuration/compose/#per-service-overrides).

- [`max_size`](/configuration/storage/#max_size), [`min_free_space`](/configuration/storage/#min_free_space)

## [daemon]

Settings for the whole daemon. [Full reference →](/configuration/daemon/)

- [`shutdown_timeout`](/configuration/daemon/#shutdown_timeout), [`timezone`](/configuration/daemon/#timezone), [`external_url`](/configuration/daemon/#external_url), [`check_updates`](/configuration/daemon/#check_updates), [`tls`](/configuration/daemon/#tls-tls_cert-tls_key), [`tls_cert`](/configuration/daemon/#tls-tls_cert-tls_key), [`tls_key`](/configuration/daemon/#tls-tls_cert-tls_key), [`metrics_enabled`](/configuration/daemon/#metrics_enabled), [`metrics_listen`](/configuration/daemon/#metrics_listen), [`trusted_proxies`](/configuration/daemon/#trusted_proxies), [`allow_station_dispatch`](/configuration/daemon/#allow_station_dispatch), [`include`](/configuration/daemon/#include), [`include_cron`](/configuration/daemon/#include_cron)

  [CLI flags](/configuration/daemon/#cli-flags-config-data-directory--listen-address),
  not config keys.
