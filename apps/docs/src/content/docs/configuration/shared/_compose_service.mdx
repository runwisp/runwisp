The service in [`compose_file`](/configuration/tasks/#compose_file) to run. `runwisp validate`
rejects a name the file doesn't define.

Without `compose_file`, set [`run`](/configuration/tasks/#run) and run RunWisp as a service of the
same compose project: RunWisp finds the project from its own container. **since**: `1.7`, see
[Without `compose_file`](/configuration/compose/#without-compose_file).

```toml title="runwisp.toml"
[tasks.nightly-backup]
compose_file    = "./docker-compose.yml"
compose_service = "backup"
```
