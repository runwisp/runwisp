**type**: `map`

Secret environment variables: passwords, tokens, API keys. They work like
[`env`](/configuration/tasks/#env), but their keys and values are never shown. To read from a file,
use [`secrets_file`](/configuration/tasks/#secrets_file).

```toml
[tasks.backup.secrets]
RESTIC_PASSWORD = "${file:~/.config/runwisp/restic.pass}"
```
