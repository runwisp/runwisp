**type**: `map`

Secret environment variables: passwords, tokens, API keys. They work like
[env](/configuration/tasks/#env), except their keys and values never leave the
daemon. To read from a file, use [secrets_file](/configuration/tasks/#secrets_file).

```toml
[tasks.backup.secrets]
RESTIC_PASSWORD = "${file:~/.config/runwisp/restic.pass}"
```
