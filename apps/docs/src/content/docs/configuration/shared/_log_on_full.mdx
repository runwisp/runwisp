**type**: `enum` **default**: `"drop_old"`

What happens when a run's log reaches [`log_max_size`](/configuration/tasks/#log_max_size).

```toml
[tasks.backup-db]
log_max_size = "50mb"
log_on_full  = "drop_old"
```

Possible values:

- `drop_old`: keep the newest output, delete the oldest
- `drop_new`: keep the first output, ignore the rest
- `kill`: stop the run and record `log_overflow`
