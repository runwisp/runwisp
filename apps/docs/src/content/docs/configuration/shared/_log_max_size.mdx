**type**: `size` **default**: `100mb`

The cap on one run's captured stdout/stderr on disk. Units are `b`/`kb`/`mb`/`gb`/`tb`.
At the cap, [log_on_full](/configuration/tasks/#log_on_full) decides what happens.
`0`, negatives, and malformed strings are rejected at load.

```toml
[tasks.backup-db]
log_max_size = "500mb"
```
