**type**: `boolean` **default**: `true`

Whether operators can start, stop, or restart it by hand. Set `false` to lock
it to its schedule (or, on a service, to supervisor-only restarts):
`runwisp start`/`stop`/`restart` and the REST API return 403, the Web UI hides
its controls, the station trigger is refused.

```toml
[tasks.backup-db]
manual_trigger = false
```
