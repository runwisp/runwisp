**type**: `boolean` **default**: `true`

Whether operators can start, stop, or restart it by hand, and
[pause its schedule](/concepts/scheduling/#pausing-a-schedule). Set `false` to
lock it to its schedule (or, on a service, to supervisor-only restarts):
`runwisp start`/`stop`/`restart`/`pause` and the REST API return 403, the Web UI
hides its controls, the station trigger is refused.
[Hooks](/operations/auth/#hooks) still work.

```toml title="runwisp.toml"
[tasks.backup-db]
# ...
manual_trigger = false
```
