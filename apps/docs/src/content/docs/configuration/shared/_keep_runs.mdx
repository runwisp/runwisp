**type**: `integer` **min**: `0` **max**: `1000000`

Keep only the N most recent completed runs. Older runs and their logs are
deleted by the hourly cleanup. `0` keeps no completed runs; unset means no
count limit. With
[`keep_for`](/configuration/tasks/#keep_for) also set, whichever deletes more wins.

```toml
[tasks.backup-db]
keep_runs = 200
```
