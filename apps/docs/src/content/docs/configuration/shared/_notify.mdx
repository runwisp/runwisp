**type**: `string[]`

Notifier ids to alert when a run ends as a failure, as decided by
[`failures`](/configuration/tasks/#failures). To stop or start alerts for an outcome (for example a
missed run), change `failures`. To alert on other outcomes (a success, for
example), add a [`[[route]]`](/notifications/routes/).

```toml
[tasks.backup-db]
notify = ["slack-ops"]
```

- Each id must be declared in a
  [`[notifiers.<id>]`](/notifications/model/#notifiersid--declaring-a-channel)
  block.
- `[notify] global_notifiers` (default `["inapp"]`) is added to every list. Set
  it to `[]` to turn that off.
- Full details: [Per-task notifications](/notifications/per-task/).
