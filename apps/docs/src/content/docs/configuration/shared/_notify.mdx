**type**: `string[]`

Notifier ids to alert when a run counts as a failure (see
[`failures`](/configuration/tasks/#failures)). A missed run is a failure by
default, so it alerts here too.

```toml
[tasks.backup-db]
notify = ["slack-ops"]
```

- Each entry is a notifier declared in `[notifiers.<id>]`, `"inapp"` (the bell),
  or `"<id>:<target>"` to reuse a notifier's credentials with another target
  (`"slack:#deploys"`, `"tg:-1009998887"`, `"mail:ops@example.com"`). See
  [`notifiers`](/configuration/routes/#notifiers) for which types accept a target.
- [`[notify] global_notifiers`](/configuration/notify/#global_notifiers)
  (default `["inapp"]`) is added to every list.
- `notify = []` is the same as leaving it out.
- To alert on other outcomes (a success, for example), use a
  [`[[route]]`](/configuration/routes/).
