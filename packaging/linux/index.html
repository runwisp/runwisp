RunWisp packages

The apt and dnf repository for RunWisp, signed and updated on every stable release. Current version: @VERSION@.

Quickest: install the package

The package adds this repository for you, so apt upgrade or dnf upgrade keeps RunWisp current. Use arm64 instead of x64 on ARM. 

# Debian, Ubuntu
curl -fLO https://github.com/runwisp/runwisp/releases/latest/download/runwisp-linux-x64.deb
sudo apt install ./runwisp-linux-x64.deb

# Fedora, RHEL
sudo dnf install https://github.com/runwisp/runwisp/releases/latest/download/runwisp-linux-x64.rpm

Debian, Ubuntu: add the repository

sudo curl -fsSLo /usr/share/keyrings/runwisp.asc https://pkg.runwisp.com/runwisp.asc
sudo curl -fsSLo /etc/apt/sources.list.d/runwisp.sources https://pkg.runwisp.com/runwisp.sources
sudo apt update && sudo apt install runwisp

Fedora, RHEL: add the repository

sudo curl -fsSLo /etc/pki/rpm-gpg/RPM-GPG-KEY-runwisp https://pkg.runwisp.com/runwisp.asc
sudo curl -fsSLo /etc/yum.repos.d/runwisp.repo https://pkg.runwisp.com/runwisp.repo
sudo dnf install runwisp
