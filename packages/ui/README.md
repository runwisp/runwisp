# @runwisp/ui

Svelte 5 UI component library for RunWisp dashboards and admin interfaces.

Built with [Svelte 5 runes](https://svelte.dev/docs/svelte/what-are-runes), [Tailwind CSS v4](https://tailwindcss.com/), and [Storybook](https://storybook.js.org/) for interactive component development.

## Development

From the repository root:

```bash
bun install
bun run theme   # starts Storybook on port 6006
```

Components live in `src/lib/`. Routes in `src/routes/` serve as a preview/showcase app for development.
